将请求封装为对象 解耦请求的发起者和执行者

角色	说明
Command（抽象命令）	定义命令接口，如 execute()
ConcreteCommand（具体命令）	实现命令逻辑，持有 Receiver（执行者）
Receiver（接收者）	真正执行命令的类
Invoker（调用者）	触发命令的对象，比如遥控器
Client（客户端）	创建命令并设置给调用者

命令模式的主要目的是解耦请求的发送者（调用者）与请求的执行者（接收者）。
它通过将请求封装为一个命令类对象，把执行逻辑从调用者中抽离出来。
每个命令类通常持有一个接收者对象，在其 execute() 方法中调用接收者的具体操作。
调用者则持有命令对象，并通过调用命令的 execute() 方法来触发操作，而无需了解命令的具体执行细节。
