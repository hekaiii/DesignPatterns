代理根据代理类生成的时机不同，分为静态代理和动态代理；
静态代理在编译代码的时候生成
动态代理在Java运行时动态生成 JDK CGLib两种

角色：
1.抽象主题类 接口或者抽象类 声明真实主题和代理对象实现的的业务方法
2.真实主题类 抽象类的实现类 最终真实引用的对象
3.代理类     提供了与真实主题相同的接口，其内部有对真实主题的引用、控制和扩展真实主题的功能

+------------------+       +---------------------+       +-----------------------+
|     Subject      |<------+     Proxy           |------>|     RealSubject       |
|------------------|       |---------------------|       |-----------------------|
| + request()      |       | - realSubject       |       | + request()           |
+------------------+       | + request()         |       +-----------------------+
+---------------------+
RealSubject和Proxy都是Subject这个接口的实现类
静态方法就是用户调用代理类 代理类聚合了真实的对象 client --> proxy --> real



JDK动态代理 只能代理接口 某个类实现类了接口 Proxy.newProxyInstance根据接口来生成实现类，实现类中对于接口的真实引用是引用你作为入参输入的invocationHandle.invoke方法
这个方法的入参有方法名，根据不同的方法名来调用具体类真实方法
执行流程如下：
1．在测试类中通过代理对象调用sell()方法
2．根据多态的特性，执行的是代理类($Proxy0)中的sell()方法
3．代理类($Proxy0)中的sell()方法中又调用了InvocationHandler接口的子实现类对象的invoke方法
4．invoke方法通过反射执行了真实对象所属类(TrainStation)中的sell()方法
